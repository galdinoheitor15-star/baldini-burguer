# Baldini Burguer

Site da Baldini Burguer, hamburgueria em Carpina - PE (antigo Bombachiando Carpina).

Site estático (HTML, CSS e JS). Para ver localmente, abra o `index.html` no navegador.

## Cardápio editável pela gestão
Preços, produtos novos e produtos escondidos são editados na aba **Cardápio** da gestão e ficam no banco (`config/cardapio`).
O `menu-ajustes.js` aplica esses ajustes ao `menu-data.js` antes de montar o cardápio (sem internet, usa os últimos guardados no aparelho).
